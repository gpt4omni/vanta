# Vanta 0.50.2

Bugfix release for `v0.50.1` fixing game window header bar focus stealing during gameplay and improving Raspberry Pi OS installation and Debian package dependencies.

## Fixed

- **Space key opening the Server Region menu in-game:** The game window's `AdwHeaderBar`, Server Region `MenuButton` pill, and popover action buttons (`Copy Invite Link`, `Copy Server Info`, `Quick Rejoin Server`) could hold GTK keyboard focus during gameplay, causing Space (Jump) or Enter in Roblox to pop open or activate the server menu. Keyboard focus is now disabled on game window header bar chrome (mouse clicks continue working normally), and GTK focus is explicitly cleared when the window maps, when the server popover closes, when an in-game text box blurs, and when an in-window dialog closes.
- **Raspberry Pi OS & Debian/Ubuntu compatibility:** Updated `.deb` dependencies to accept Debian 13 (Trixie) / Ubuntu 24.04+ `t64` package names (`libglib2.0-0t64 | libglib2.0-0`, `libpipewire-0.3-0t64 | libpipewire-0.3-0`), and updated `install.sh` to simulate APT dependencies before choosing APT, fall back cleanly to Flatpak or AppImage (with automatic FUSE2-free launch wrapper) when `libwebkitgtk-6.0-4` is unavailable, and detect 32-bit Raspberry Pi OS userspace on 64-bit kernels.
