# Vanta 0.50.0: New Logo, Speed Launch Mode, Fixed FastFlags, Embedded WebViews, and Massive Startup/RAM/Runtime Overhaul

Vanta `0.50.0` is our biggest release yet: a fresh visual identity, a dedicated **Speed** launch mode built for old and weak CPUs, a complete FastFlag reliability overhaul (including fixing `DFIntDebugFRMQualityLevelOverride` render distance), embedded WebViews for Servers and Roblox pages, an obsidian UI redesign, and major startup, RAM, and runtime performance breakthroughs, all with zero in-process hooking or patching of `libroblox.so` (ADR-001).

## Highlights

### New Identity & Redesigned Obsidian UI
- **New tilted-square Vanta logo** rolled out as pure vector SVG across app icons (including Frostbite), banners, docs, Discord bot avatar, and OpenGraph social previews.
- **Redesigned launcher & Settings:** elevated obsidian hero card, recessed **`Balanced | Performance | Speed`** launch mode switcher right in the launcher, a live Quick Status Strip (profile, mode, Roblox build), and tabular-nums in-game HUD and server pills.
- **Faster, lighter UI:** launcher now defaults to `GSK_RENDERER=cairo` (restoring your original `GSK_RENDERER` when launching `vanta-run`), skips the blocking 500 ms startup portal D-Bus call and hardcoded 400 ms `--play` sleep, trims heap with `malloc_trim(0)`, uses a lightweight `HostWindow::new_launcher`, lazy-loads heavy Settings pages off the main thread, and fixes a `StyleManager` `TextBuffer` leak on every Settings open.
- **Upgraded `Settings > FastFlags`:** added a Render Quality Lock (`DFIntDebugFRMQualityLevelOverride`) dropdown synced to the editor, one-click preset chips (`Speed / Weak CPU`, `Max FPS`, `Clean Visuals`, `Format JSON`, `Copy`), inline search, live per-flag type/prefix validation, debounced highlighting, and live `DF*` reload on running games when clicking Apply.

### FastFlags Overhaul & `Speed` Launch Mode
- **Fixed `DFIntDebugFRMQualityLevelOverride` collapsing render distance.** Disassembly of `libroblox.so` showed that Android's `GoogleAndroidApp` document sets `FFlagFRMLockstepOverridesEffective = True`, causing `FRM::getDistanceSquared()` to ignore the preserved slider distance and clamp to 500 studs. Vanta now automatically sets `FFlagFRMLockstepOverridesEffective = False` whenever `DFIntDebugFRMQualityLevelOverride` is in `1..=21` (unless explicitly overridden by the user).
- **Fixed the initial 2 to 4 second `DF*` startup wipe.** `game_log` now catches `[DFLog::FlagCache]` writes and `flag_reapply` runs a one-shot 5-second post-startup settle re-apply so dynamic flags stay active from the start instead of reverting for the first two minutes.
- **New `Speed` launch mode (`VANTA_PERFORMANCE=speed`).** Applies a 53-flag `libroblox.so`-verified configuration built for ultra-weak/old CPUs and iGPUs: locks FRM quality to 1 while preserving render distance, disables MSAA/bloom/clouds/grass/anisotropic filtering/roughness, cuts envmap raycasts 8x and texture upload mips 4x, caps terrain/voxel/particle/audio CPU budgets, prevents 8-thread thrashing on 2-core CPUs, and raises `ALooper` zero-timeout coalescing to 500 us.
- **Cleaned up FastFlags:** removed dead `FFlagGcInParallelWithRenderPrepare3`, properly differentiated `Balanced`/`Throughput`/`Latency`, normalised JSON booleans and whole floats in `flags.json`, bridged `VantaDeviceProfile`, and added live `Update::ReloadFlags` delivery from Settings.

### Embedded WebView Fix ("Servers" & Roblox Pages Stay Inside Vanta)
- **Registered `WebView.isAvailable` and `mutateWindow`** in `webview::arm()` before calling `initializeAndroidWebViewProtocol`, and installed the presenter before arming so Roblox Lua no longer falls back to the external browser.
- **Routed `roblox.com` links in `Linking.openURL` to Vanta's embedded WebView** (keeping external non-Roblox links opening in your browser), wired legacy `openNativeOverlay` and DataModel WebView notifications (`OPEN_CUSTOM_WEBVIEW`, `VIEW_PROFILE`, `PURCHASE_ROBUX`), added standalone `adw::Window` WebView support on X11, and fixed the `.ROBLOSECURITY` cookie seeding race against `load_uri()`.

### Startup Speed, Lower RAM, & Runtime Throughput Overhaul
- **On-disk `VkPipelineCache` & lazy GPU ETC2 initialization:** persists the compiled SPIR-V compute pipeline to `~/.cache/vanta/` (cutting ~1.05 s warm NVIDIA startup stalls down to ~1 to 5 ms), skips allocating GPU decoder resources for probe `VkDevice`s, shrinks staging pools (`4 MiB` chunks, max 2 pooled) with a 9 s idle trim sweep, and fixes a `Box<Dev>` leak in `forget_device()`.
- **Much lower RAM usage:** removed eager 1 GiB `MIMALLOC_RESERVE_OS_MEMORY` / `ARENA_EAGER_COMMIT` / `PURGE_DECOMMITS=0` defaults, replaced `patches/0009`'s 102 MiB anonymous `pread64` copy with file-backed `r-xp` `MADV_HUGEPAGE`, served extracted `AAssetManager` files via `mmap` instead of `Vec::leak()`, tightened `MADV_FREE` elision to `< 256 KiB` (`< 128 KiB` on 4 to 7 GiB hosts) so freed game RAM returns to Linux, and switched release debuginfo to `line-tables-only`.
- **Faster `vanta-run` cold boot:** replaced `fork`/`exec` of `df` with `libc::statvfs()`, stamp-gated the 715-font symlink walk, backgrounded `gamemode::register()`, cached `asset_folder()`, freed `BOOTSTRAP.settings` after delivery, and skipped the redundant 250 ms `vanta-late-post` pre-sleep when `post_gate` is enabled.
- **JNI Rocket v2 & ETC2/Vulkan hot paths:** eliminated `3x __dynamic_cast` + `4x` atomic RMWs per virtual JNI call via `(vptr, mid)` caching and direct `MotionEvent` handles, hooked `Exception*`, `Push/PopLocalFrame`, `Get/Set*Field`, `NewObject*`, and `ObjectArray` calls, cached `jclass` and reused `MotionEvent` per mouse packet, switched all 10 Vulkan handle maps from SipHash to FxHash with stack-backed batch buffers, wired inline `<= 64x64` CPU ETC2 decode, replaced 16 integer divisions per BC4 block with 1 bit-exact reciprocal on both GPU and CPU + SSE2/NEON BC1, gated asset overlay checks on a single atomic load when no mods are active, added lock-free SPSC OpenSL/Java PipeWire playback and fixed-ring `liblog`, and built native C++ shims with `-O3 -fno-semantic-interposition`.

### Security & Stability Bugfixes
- **APK signature SPKI binding & overflow fix (`apk_signature.rs`):** verifies `TBSCertificate.subjectPublicKeyInfo == public_key` byte-for-byte and uses `checked_add(8)` on signing block sizes.
- **Wayland dialog keystroke isolation:** stops keystrokes typed inside open WebViews (including passwords/2FA) from leaking into Roblox and drains held keys when dialogs open.
- **System paths `O_TMPFILE` bitmask UB fix:** properly tests `(flags & O_TMPFILE) == O_TMPFILE` so `O_DIRECTORY` opens no longer trigger `va_arg` UB or bypass mod overlays.
- **Recording (`F9`) reliability:** moves resize `close_encoding` off `vkQueuePresentKHR`, retires Vulkan `Readback` teardown strictly on the Vulkan thread, moves `ffmpeg` probes outside `SESSION.lock()`, and chains `VkPresentInfoKHR::pWaitSemaphores`.
- **Plugin host hardening:** fixes `events.publish` deadlock, canonicalizes `assets.override` against symlink escapes, caps plugin stdout lines at 1 MiB against OOM, and uses non-blocking `offer()` in `Session::publish`.
- **Input, audio & presence fixes:** releases stranded X11 mouse buttons on `FOCUS_OUT`, coalesces high-Hz X11/Wayland mouse motion, fixes `AAudioStream_read` `INT64_MAX` signed overflow UB, and prevents stale async game-metadata lookups from overwriting Discord Rich Presence after leaving or switching games.

## Install & Upgrade

```bash
curl -fsSL https://gpt4omni.github.io/vanta/install.sh | bash
```

Flatpak, APT, DNF, and Pacman repositories are GPG-signed, and all GitHub Release packages (`x86_64` and `aarch64`) are signed with keyless Sigstore/cosign.

## Known limitations

- **Live ARM64 gameplay testing on 16 KiB-page hardware (Asahi Linux / Raspberry Pi 5)** is still early and welcomes user feedback with `vanta --diagnostics`.
- **If you see texture glitches on NVIDIA**, test with `VANTA_NO_GPU_ETC_DECODE=1` and share `vanta --diagnostics` on GitHub Issues or Discord (https://discord.gg/Jt5MW7UBsC).
