# Vanta 0.50.1

Hotfix release for `v0.50.0` fixing an immediate crash when entering a Roblox experience on GPUs using Vulkan ETC2 emulation (including NVIDIA).

## Fixed

- **Crash when entering a Roblox experience (`SIGSEGV` in `libnvidia-glcore.so`):** In `v0.50.0`, `vulkan.rs` began intercepting `vkDestroyDevice` for recording readback cleanup before `vulkan_etc::hook` could see it. When Roblox tore down its Home screen `VkDevice` and created a new `VkDevice` for the experience, `vulkan_etc` still held the old device state and tried to destroy its compute pipeline and staging buffers on the already-destroyed `VkDevice` handle. `vk_destroy_device` now notifies `vulkan_etc::device_destroying(device)` before forwarding to the host loader, and `vulkan_etc::device_created` no longer invokes Vulkan destroy calls if an un-notified stale device is ever replaced.
