# Vanta 0.40.0: major FPS & 1% lows overhaul, Live Perf HUD, Asset Mod Manager, and Server Region tools

This release combines a ground-up throughput and 1% lows performance overhaul
with three new headline features — all implemented strictly at Vanta's
framework, loader, Vulkan, Wayland, and FastFlag boundaries with zero
in-process hooking or binary patching of `libroblox.so` (ADR-001).

## What you can do now

### New features

- **Built-in Live Performance HUD (`F8` toggle + Settings).** Press `F8` in
  game (or enable **Performance HUD** under Settings → General → Performance,
  or set `VANTA_PERF_HUD=1`) for a live monospace pill in the headerbar showing
  **FPS, 1% low FPS, and average frametime**, with full **0.1% low** and **P99
  frametime** details in the tooltip and automatic window-title fallback when
  the headerbar is hidden or fullscreen. Powered directly by Vanta's lock-free
  `frame_pacing` ring buffer with zero per-frame overhead when disabled.
- **Non-Destructive Asset Modding Manager (`Settings → Mods`).** Overlay custom
  fonts, cursors, skyboxes, textures, or classic audio from
  `<profile>/mods/<pack>/` directly on top of `base.apk` without ever modifying
  the APK, so mods survive every Roblox update automatically. Includes a
  dedicated **Mods** tab in Settings with a global toggle (`VANTA_NO_MODS=1`
  when off), ZIP and folder import (with zip-slip and path-traversal
  protection), per-pack enable/disable switches, priority ordering, and an
  **Open Mods Folder** button.
- **Local Server Region Detector, Copy Invite Link & Quick Rejoin.** Reads
  server connection info from Roblox's game log and resolves Roblox AS22697
  datacenter regions **100% locally** (zero external network lookups or
  tracking). Adds a live **Server Region** pill to the headerbar with one-click
  **Copy Invite Link**, **Copy Server Info**, and **Quick Rejoin Server**, plus
  toggleable join notifications under Settings → General → Session.
- **Uncapped FPS setting & higher replacing-mode headroom.** Adds an explicit
  **Uncapped (`999`)** option to Settings → Graphics → Frame rate limit, raises
  replacing-mode (`MAILBOX`/`IMMEDIATE`) `Display` headroom to `4.0×` refresh
  (floor `240`, ceiling `999`) while keeping `FIFO` locked to exact display
  refresh, and fixes `Display` clobbering `fps-flex` plugin caps.

### Performance & 1% lows breakthroughs

- **GPU compute ETC2/EAC → native hardware BC1/BC3/BC4/BC5 transcoding &
  zero-contention `vulkan_etc`.** On GPUs without native ETC2 (such as NVIDIA),
  Vanta now transcodes ETC2/EAC directly to hardware BC1–BC5 on the GPU (4×–8×
  less VRAM and texture bandwidth vs RGBA8; verified bit-for-bit on GTX 1080 Ti
  at `0.186–0.259 ms` for 1024×1024). Replaced saturating Bloom filters with
  16 KiB lock-free `CountingBloom4K` filters, bypassed global write locks for
  non-staging buffers and unmapped `DEVICE_LOCAL` `vkFreeMemory`, pre-warmed
  `2 × 8 MiB` GPU scratch chunks and descriptor pools at device init, cached
  descriptor sets across regions, and moved CPU fallback decode workers to
  `SCHED_BATCH` + `nice(+5)`.
- **1% lows & kernel/allocator pacing.** Maps `libroblox.so`'s 105.6 MB `.text`
  and large anonymous allocations with **2 MiB transparent huge pages**,
  elides advisory sub-4 MiB `madvise(MADV_FREE)` TLB-shootdown storms on hosts
  with `>= 8 GiB` RAM (`VANTA_NO_MADVISE_FILTER=1` opt-out; host microbench
  `max = 3.26 ms` → ~1 ns while `MADV_DONTNEED` zeroing semantics stay
  untouched), promotes plain private mutexes to **`PTHREAD_MUTEX_ADAPTIVE_NP`**
  (`VANTA_NO_ADAPTIVE_MUTEX=1` opt-out; host microbench **4.3× lower contended
  p99**: `1,140 ns → 265 ns`), adds brief `cond_wait` spinning, in-place
  zero-alloc futex `sem_t`/`pthread_cond_t`, TLS-cached `gettid`/`getpid`, and
  `prctl(PR_SET_TIMERSLACK, 1)` for 1 ns wakeup precision.
- **Swapchain, Wayland, JNI, DNS & flag re-apply latency.** Raises replacing-mode
  swapchains to a **4-image ring**, adds Wayland **`wp_tearing_control_v1`**
  async presentation for `immediate`/`uncapped`/`VANTA_TEARING=1`, enables
  `libjnivm` Rocket fast-path hooks (**2.4×–1,063×** faster in JNI
  microbenchmarks), adds a thread-safe positive + negative + singleflight DNS
  cache (`202 ns` cached negative hit), shrinks periodic 120s `flag_reapply`
  payloads from 1.5 MB to a ~300-byte delta JSON on a `nice(+10)` worker, fixes
  a dead-code clamp in `ALooper` adaptive backoff, splits 1000 Hz mouse drain
  from 16 ms housekeeping, deduplicates paired GTK typing redraw bursts, and
  enables desktop Vulkan pooling FastFlags
  (`FFlagGraphicsVulkanExtendedDynamicState`,
  `FFlagVulkanAllocatorPoolSmallOnly=False`,
  `FIntVulkanAllocatorKeepEmptyPages=8`) plus implicit Vulkan layer hygiene
  (`NODEVICE_SELECT=1`, `DISABLE_LAYER_MESA_ANTI_LAG=1`).

## What is still broken

- **First launch after upgrading rebuilds the Vulkan pipeline cache once** due
  to `FFlagGraphicsVulkanExtendedDynamicState=True` changing the cache key; a
  fresh cache is saved automatically on exit so subsequent launches load cleanly.
- **If you see missing/corrupted textures on NVIDIA**, test with
  `VANTA_NO_GPU_ETC_DECODE=1` and attach the log to an issue.
- **Signed-in startup freezes ([#92](https://github.com/gpt4omni/vanta/issues/92))
  and window creation on some COSMIC/KWin/wlroots setups
  ([#38](https://github.com/gpt4omni/vanta/issues/38))** remain open for
  reports; `aarch64` passes CI on real ARM64 hardware but live ARM64 gameplay
  testing is still early.
- **The Flatpak remote is currently unsigned** (`gpg-verify=false`) until a GPG
  signing key is configured; native `.deb`, `.rpm`, `.pkg.tar.zst`, AppImage,
  and Flatpak release bundles attached to GitHub Releases are signed with
  keyless Sigstore/cosign.
