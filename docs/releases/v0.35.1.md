# Vanta 0.35.1: fixes JNI_OnLoad startup crash

## What you can do now

- **Vanta starts again instead of aborting during `JNI_OnLoad`.** On 0.35.0,
  launching Roblox stopped immediately with an uncaught C++ exception on a
  worker thread: `what(): Failed to get reference to jnivm::VM`. The JNI
  invocation wrapper now keeps `libjnivm`'s internal `JavaVM` isolated and
  always delegates `GetEnv`, `AttachCurrentThread`, and `DetachCurrentThread`
  to it, while preserving the thread-local `JNIEnv` cache.
- **Vanta branding and logos everywhere.** Replaces the remaining old logos,
  palette colours, and stale references across the documentation site, GitHub
  Pages header icon, Discord bot avatar, and ADRs.

## What is still broken

**In-game frame rates and stutter percentiles on 0.35.x remain INFERRED, not
measured in a live Roblox session.** If you see missing or corrupted textures
on NVIDIA or other GPUs without native ETC2, test with
`VANTA_NO_GPU_ETC_DECODE=1` and include the result in a report.

The rest of the list in the
[0.35.0 notes](https://github.com/gpt4omni/vanta/releases/tag/v0.35.0) still
applies.
