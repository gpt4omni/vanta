# Vanta 0.45.0: Niri & Wayland fixes, working AppImage, full ARM64 support, and runtime stability & performance overhaul

This release fixes the blank AppImage launch bug, resolves the Niri Wayland mouse-blocking window and pointer-lock issue, brings ARM64 (`aarch64`) support to full parity (including 16 KiB and 64 KiB page kernels), and ships a major wave of runtime performance and correctness fixes.

## Highlights

### AppImage Fix (No More Blank Window)
- **Removed host-driver library poisoning.** The Ubuntu 24.04 AppImage previously bundled 29 host-coupled libraries (`libvulkan.so.1`, `libwayland-*`, `libX11`/`libxcb*`, `libexpat.so.1`, `libzstd.so.1`, `libelf.so.1`, `libffi.so.8`, `libfontconfig.so.1`, and more) ahead of host Mesa/NVIDIA drivers via `LD_LIBRARY_PATH`. Those libraries are now actively pruned and guarded by post-build assertions.
- **Reliable GTK4 rendering in AppImage.** `AppRun` now defaults `GSK_RENDERER=cairo` for the lightweight GTK launcher and host window headerbar (leaving the game's Vulkan subsurface untouched), avoiding Ubuntu 24.04 GTK 4.14 `ngl` blank-window bugs on Wayland/NVIDIA/Mesa.
- **Cross-distro WebKitGTK & runtime modules.** Rewrote Ubuntu's baked-in `/usr/lib/<arch>-linux-gnu/webkitgtk-6.0` strings in `libwebkitgtk-6.0.so.4` to `/usr/libexec/webkitgtk-6.0` (including `injected-bundle/`) so sign-in WebViews work on Arch, Fedora, openSUSE, Ubuntu, and Debian alike. Bundled `gdk-pixbuf` SVG/image loaders, `gio` modules, and Adwaita/hicolor icon themes.

### Niri & Wayland / X11 Windowing Fixes
- **Fixed Niri mouse-blocking windows and stuck pointer locks.** Added Niri detection (`NIRI_SOCKET` / `XDG_CURRENT_DESKTOP`) so Vanta constrains the GTK toplevel with `ONESHOT` pointer constraints instead of a persistent subsurface lock, and explicitly releases held pointer locks whenever the window loses focus.
- **Replaced separate blocking modal launcher windows.** Converted the startup progress window (`starting_dialog_with`), updater dialog, crash dialog, and instructions dialog into in-window `adw::Dialog` overlays and guarded background auto-updater popups when the launcher is hidden (`--play` / browser join).
- **Fixed WebView popup dialog refcount desync and X11 editor focus loss.** WebView `window.open()` popups now track the same `dialog_up` refcount as primary WebViews so closing them never leaves clicks swallowed, and the X11 override-redirect text editor withdraws cleanly when focus leaves the game window.
- **Fixed Wayland `wp_tearing_control_v1` Error 71 disconnect.** Stopped attaching a duplicate tearing-control object on Vulkan surfaces (where Mesa/NVIDIA Wayland WSI already owns it), limiting it to GLES/EGL and destroying proxies cleanly on teardown.
- **Fixed X11 Performance HUD and HUD/Recording title collisions.** `F8` Performance HUD now updates cleanly on X11, and combining `F8` (HUD) with `F9` (Recording) preserves both indicators cleanly in the window title.

### Full ARM64 (`aarch64`) Support
- **16 KiB & 64 KiB page kernel linker support + I-cache coherency.** Added runtime host page-size detection (`sysconf(_SC_PAGESIZE)`) in `mcpelauncher-linker` (`patches/0010`), enabling zero-copy `r-xp`/`r--p`/`rw-p` mapping for Android 15 16 KiB-aligned libraries and safe RW-stage + `__builtin___clear_cache` + per-page `mprotect` fallback for legacy 4 KiB-aligned libraries on Asahi Linux and Raspberry Pi 5. Added `__builtin___clear_cache` to `patches/0009` as well.
- **ARM64-only Roblox releases via XAPK split bundles.** `vanta-update` now inspects and extracts nested `.xapk` bundles (verifying Roblox's signing certificate on every inner APK) and queries `arm64-v8a` on `aarch64` hosts.
- **Hardened `aarch64` bionic `pthread` ABI shims.** Added missing `pthread_attr_*` and `pthread_mutex_clocklock` wrappers, mirrored adaptive mutexes on `aarch64`, and added host page-size reporting to `vanta --diagnostics` and `vanta --doctor`.
- **Full packaging & build parity.** Enabled `aarch64-linux` in `flake.nix` and `packaging/nix/package.nix`, added `aarch64` to AUR `PKGBUILD`s/`.SRCINFO` and multi-arch `packaging/pacman/build-repo.sh`, guarded CMake `POST_BUILD` tests for cross-compilation, and cleaned up CI workflows.

### Performance & Core Bugfixes
- **Eliminated ~3,000 syscalls/sec `game_log::poll()` storm** on the input pump thread by throttling polls to 5 Hz and keeping the active log FD open across ticks.
- **Async 3-slot `VkFence` recording readback ring (`F9`)** replacing synchronous `vkQueueWaitIdle` pipeline stalls during video capture.
- **Lock-free SPSC PipeWire audio capture ring** plus fixes for a critical live-retarget use-after-free and concurrent `round_trip()` race in `pipewire_backend.cpp`.
- **Asset Mod Manager (`<profile>/mods/`) wired into `native/system_paths.cpp`** so extracted filesystem assets actually load mod overrides, alongside symlink-cycle protection, real ZIP decompression caps, zero-alloc lookup fast paths, and eliminating the startup double walk.
- **Eliminated `bionic_mmap` `MADV_HUGEPAGE` VMA splitting** (and enabled huge pages on exact 2 MiB allocations) and accelerated startup `symtab::build()` with cached `dli_fbase` pointer comparisons and `libc` short-circuiting.
- **Core safety & correctness fixes:** fixed Rocket JNI `Weak` ref UAF, parent-frame `LocalRef` deletion, and array region bounds checks (`jni_shim.cpp`); fixed `ALooper` cross-thread `Mutex` safety, `epoll` FD leak, and `EPOLL_CTL_MOD` re-add; fixed `vulkan_etc.rs` `BUFFERS` bloom false-positive leaks and transactional GPU batch allocation; fixed stale Server Region state on same-place server hops; and fixed `_SC_NPROCESSORS_*`, `sem_*` null errno handling, and `cond_timedwait` negative timeout handling.

### Revamped README & Links

## What is still broken or limited

- **Live ARM64 gameplay testing on 16 KiB-page hardware (Asahi Linux / Raspberry Pi 5)** is newly enabled by this release and needs real-hardware feedback.
- **The Flatpak remote is currently unsigned** (`gpg-verify=false`) until a GPG signing key is configured; release artifacts attached to GitHub Releases are signed with keyless Sigstore/cosign.
- **If you hit texture glitches on NVIDIA**, test with `VANTA_NO_GPU_ETC_DECODE=1` and share `vanta --diagnostics` on GitHub Issues or Discord.
